# MOTHER 3 Recomp

MOTHER 3 for Windows, Linux and Android, built with gbarecomp and recomp-ui.
Bring your own ROM and game files.

| Platform | Version | Download |
| --- | --- | --- |
| Windows x64 | 1.0.4 | [Windows ZIP](https://github.com/josiahg2502-glitch/Mother3Recomp/releases/download/v1.0.4/Mother3Recomp-v1.0.4-windows-x64.zip) |
| Linux x86_64 / Steam Deck | 1.0.4 | [Linux archive](https://github.com/josiahg2502-glitch/Mother3Recomp/releases/download/v1.0.4/Mother3Recomp-v1.0.4-linux-x86_64.tar.gz) |
| Android ARM64 | 1.0.5 | [Android APK](https://github.com/josiahg2502-glitch/Mother3Recomp/releases/download/v1.0.5/Mother3Recomp-v1.0.5-android.apk) |

**v1.0.5 updates Android only.** Windows and Linux remain on v1.0.4.

## Start playing

1. Download and extract your platform's package, or install the Android APK.
2. Open the game and select your ROM, patch and BIOS as needed.
3. Choose **Play**.

## Project status

Language patches include Spanish; compatibility and speed vary by patch.
Android v1.0.5 has reported startup, performance and adaptive-display issues.
[Known issues](https://github.com/josiahg2502-glitch/Mother3Recomp/issues) track these reports; the 1.0.6 fixes are under review.
